# Content Representation in the Neocortex During Autobiographical Memory Recall - Master's thesis

# About

This repository contains Python code for the neuroimaging analyses conducted as part of a Master's thesis investigating content representation during autobiographical memory recall using functional magnetic resonance imaging.

The analysis examines whether information associated with different autobiographical memory content categories can be discriminated from patterns of neural activity within selected cortical regions of interest (ROIs).

This analysis contains:

1. ROI masks creation for contrast and conjunction maps 
2. Within-task multiclass classification using linear support vector machines & ROC AUC estimation
3. Cross-task classification between autobiographical memory and picture description tasks ( AB, PD tasks)
4. Groupwise cross-validation
5. Permutation analysis
